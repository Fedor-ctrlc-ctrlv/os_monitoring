# OS Monitoring Agent with Security Scanning

## Обзор
Кастомный агент мониторинга системы на Go, который экспортирует метрики в Prometheus и включает сканирование уязвимостей в CI/CD пайплайн. Разработан в рамках дипломного проекта «Разработка автоматизированной системы аудита и обнаружения локальных атак для Linux».

Проект демонстрирует принципы построения observability-стека с нуля: от написания собственного экспортера метрик до настройки безопасности контейнеров и автоматизации проверок.

## Архитектура
- **Агент**: Конкурентное Go-приложение, использующее горутины и каналы для сбора метрик CPU/RAM через библиотеку `gopsutil`. Не блокирует основной поток при сборе данных.
- **Экспорт метрик**: Кастомный HTTP-эндпоинт `/metrics` в формате Prometheus text exposition format. Позволяет интегрироваться с любым совместимым бэкендом без привязки к конкретной библиотеке.
- **Инфраструктура**: Docker Compose с изолированной bridge-сетью. Секреты (пароли Grafana) вынесены в `.env` файл, который добавлен в `.gitignore`.
- **CI/CD**: GitHub Actions пайплайн, включающий линтинг (`golangci-lint`), юнит-тесты, сборку Docker-образа и сканирование на уязвимости (`Trivy`). Пайплайн блокирует мерж при обнаружении критических CVE.

## Технологический стек
Go 1.24 | Docker | Prometheus | Grafana | GitHub Actions | Trivy | gopsutil | Linux (/proc filesystem)

## Быстрый старт

### Предварительные требования
- Docker & Docker Compose
- Go 1.24+ (для локальной разработки)

### Запуск стека
```bash
# Клонируйте репозиторий
git clone https://github.com/Fedor-ctrlc-ctrlv/os_monitoring.git
cd os_monitoring

# Создайте файл .env с паролем для Grafana
echo "GRAFANA_ADMIN_PASSWORD=YourSecurePassword" > .env

# Соберите и запустите все сервисы
docker compose up --build
